# 医美IP内容生产标准作业程序（SOP）

## SOP-001：科普内容生产标准流程

### 目的
确保科普内容的专业性、准确性和合规性，建立标准化的内容生产流程。

### 适用范围
适用于所有医美科普类内容的策划、创作、审核和发布。

### 流程步骤

#### 第一步：选题策划（1-2天）
**负责人**：内容策划人员
**时间要求**：每周一完成下周选题计划

**具体步骤**：
1. **热点分析**
   - 监测行业热点话题
   - 分析用户关注问题
   - 识别科普需求点

2. **选题评估**
   - 专业相关性评分（1-5分）
   - 受众关注度评分（1-5分）
   - 合规风险评估（低/中/高）
   - 内容创新性评分（1-5分）

3. **选题确定**
   - 选择总分8分以上且合规风险为低的选题
   - 制定内容大纲和关键信息点
   - 确定目标受众和传播平台

**输出文件**：《选题策划表》

#### 第二步：内容创作（2-3天）
**负责人**：专业内容创作者
**时间要求**：选题确定后3个工作日内完成

**六段式结构要求**：
1. **问题段**（200-300字）
   - 明确阐述要解决的问题
   - 描述问题的普遍性和重要性
   - 引起读者共鸣和关注

2. **背景段**（300-400字）
   - 提供相关的医学背景知识
   - 引用权威数据和研究结果
   - 说明问题产生的原因

3. **方法段**（400-500字）
   - 详细介绍解决方案或预防方法
   - 提供具体可操作的建议
   - 说明方法的科学依据

4. **案例段**（300-400字）
   - 提供真实案例说明（需脱敏处理）
   - 展示方法的实际应用效果
   - 注意强调个体差异

5. **总结段**（200-300字）
   - 总结核心观点和要点
   - 强调重要注意事项
   - 提醒合规要求

6. **行动段**（200-300字）
   - 提供具体的行动建议
   - 引导读者正确就医
   - 包含必要的免责声明

**内容要求**：
- 总字数1500-2500字
- 语言通俗易懂，避免过多专业术语
- 逻辑清晰，层次分明
- 必须包含参考文献或数据来源

**输出文件**：《内容初稿》

#### 第三步：专业审核（1天）
**负责人**：执业医师
**时间要求**：收到初稿后1个工作日内完成

**审核要点**：
1. **医学准确性**
   - [ ] 医学概念表述是否准确？
   - [ ] 数据引用是否正确？
   - [ ] 治疗建议是否合理？
   - [ ] 风险提示是否充分？

2. **内容完整性**
   - [ ] 六段式结构是否完整？
   - [ ] 关键信息是否遗漏？
   - [ ] 逻辑关系是否清晰？
   - [ ] 参考来源是否充分？

3. **实用性评估**
   - [ ] 建议是否具有可操作性？
   - [ ] 内容是否符合目标受众需求？
   - [ ] 是否有助于提升健康意识？

**输出文件**：《专业审核报告》

#### 第四步：合规审核（1天）
**负责人**：合规专员
**时间要求**：专业审核通过后1个工作日内完成

**审核清单**：
1. **禁用词汇检查**
   - [ ] 是否包含"最好"、"最佳"等绝对化表述？
   - [ ] 是否有效果承诺类表述？
   - [ ] 是否有夸大宣传表述？

2. **必要声明检查**
   - [ ] 个体差异声明是否完整？
   - [ ] 风险提示是否充分？
   - [ ] 专业咨询建议是否包含？
   - [ ] 免责声明是否完整？

3. **合规风险评估**
   - [ ] 内容是否存在违法风险？
   - [ ] 平台规则符合度如何？
   - [ ] 是否需要额外的合规处理？

**输出文件**：《合规审核报告》

#### 第五步：编辑优化（半天）
**负责人**：内容编辑
**时间要求**：合规审核通过后半个工作日内完成

**优化内容**：
1. **文字优化**
   - 语言表达优化
   - 错别字检查
   - 标点符号规范

2. **格式调整**
   - 段落结构优化
   - 标题层级规范
   - 重点内容标注

3. **配图选择**
   - 选择合规的配图
   - 确保图片清晰度
   - 添加必要的图片说明

**输出文件**：《最终版本》

#### 第六步：发布执行（半天）
**负责人**：运营人员
**时间要求**：收到最终版本后半个工作日内完成

**发布流程**：
1. **平台适配**
   - 根据不同平台特点调整格式
   - 添加平台特定的标签和话题
   - 设置合适的发布时间

2. **发布执行**
   - 按计划时间发布内容
   - 监控发布状态
   - 记录发布数据

3. **效果监控**
   - 监测用户反馈
   - 记录互动数据
   - 及时处理问题评论

**输出文件**：《发布记录表》

### 质量控制标准

#### 内容质量标准
- 医学准确性：100%
- 合规符合度：100%
- 可读性评分：≥4.0（5分制）
- 用户满意度：≥80%

#### 时效性要求
- 热点内容：3天内完成
- 常规内容：5天内完成
- 紧急内容：1天内完成

#### 审核通过率目标
- 专业审核一次通过率：≥80%
- 合规审核一次通过率：≥90%
- 最终发布成功率：100%

### 异常处理程序

#### 审核不通过处理
1. **专业审核不通过**
   - 内容创作者根据反馈修改
   - 重新提交专业审核
   - 必要时请教外部专家

2. **合规审核不通过**
   - 立即停止后续流程
   - 分析违规原因
   - 重新修改后再次审核

#### 发布后问题处理
1. **用户投诉**
   - 24小时内响应
   - 核实投诉内容
   - 采取相应处理措施

2. **平台违规警告**
   - 立即下架相关内容
   - 分析违规原因
   - 制定整改措施

### 记录与存档

#### 必要记录
- 选题策划记录
- 审核意见记录
- 修改历史记录
- 发布效果记录

#### 存档要求
- 所有文件保存期不少于2年
- 建立电子档案系统
- 定期备份重要文件

---

**注意事项**：
1. 严格按照SOP执行，不得省略任何步骤
2. 所有审核必须有书面记录
3. 发现问题及时上报，持续改进流程
4. 定期对SOP进行评估和更新
