# 医美IP内容合规检查清单

## 内容发布前检查清单

### 基础合规检查
- [ ] **标题检查**：标题是否含有禁用词汇（最好、最佳、第一、唯一等）？
- [ ] **内容审查**：正文是否包含效果承诺或绝对化表述？
- [ ] **图片合规**：使用的图片是否涉及患者隐私或夸大效果？
- [ ] **数据验证**：引用的数据是否有可靠来源和引用标注？
- [ ] **声明完整**：是否包含所有必要的合规声明？

### 禁用词汇检查
- [ ] 绝对化词汇：最、第一、唯一、完美、神奇、奇迹
- [ ] 效果承诺：保证、确保、100%、立即、永久、彻底
- [ ] 夸大宣传：革命性、突破性、颠覆性、国际领先、世界一流
- [ ] 医疗术语：治愈、根治、康复、疗效、药物名称
- [ ] 比较级词汇：更好、优于、超越、领先、高于

### 必要声明检查
- [ ] **个体差异声明**："效果因个人体质、年龄、皮肤状况等因素而异"
- [ ] **风险提示声明**："任何医疗美容项目都存在一定风险"
- [ ] **专业咨询建议**："请在专业医生指导下谨慎选择"
- [ ] **正规机构提醒**："建议到具备相应资质的正规医疗机构"
- [ ] **免责声明**："本内容仅供参考，不构成医疗建议"

## 不同内容类型专项检查

### 科普教育类内容
- [ ] 是否避免针对具体疾病的诊断建议？
- [ ] 是否避免推荐具体药物或治疗方案？
- [ ] 是否强调内容仅供参考？
- [ ] 是否提醒读者咨询专业医生？
- [ ] 医学术语使用是否准确？

### 案例分享类内容
- [ ] 是否获得患者书面授权？
- [ ] 是否保护患者隐私（面部马赛克处理）？
- [ ] 是否避免使用患者真实姓名？
- [ ] 是否客观描述治疗过程？
- [ ] 是否说明可能的风险和并发症？
- [ ] 是否强调个体差异？

### 技术介绍类内容
- [ ] 技术描述是否客观准确？
- [ ] 是否避免夸大技术先进性？
- [ ] 是否说明技术适用范围和限制？
- [ ] 是否介绍可能的风险和副作用？
- [ ] 是否提及术后护理要求？

### 机构宣传类内容
- [ ] 资质描述是否真实准确？
- [ ] 是否避免使用"最好"、"第一"等表述？
- [ ] 环境展示是否真实不夸大？
- [ ] 医生介绍是否符合实际情况？
- [ ] 是否避免承诺具体治疗效果？

## 平台特殊要求检查

### 微信公众号
- [ ] 文章标题是否符合微信规范？
- [ ] 是否避免诱导分享和关注？
- [ ] 外链使用是否合规？
- [ ] 原创声明是否真实？
- [ ] 文末免责声明是否完整？

### 抖音/快手短视频
- [ ] 视频内容是否符合平台社区规范？
- [ ] 是否避免展示具体治疗过程？
- [ ] 封面图是否合规不夸大？
- [ ] 标题和描述是否避免违规词汇？
- [ ] 是否正确使用相关话题标签？

### 小红书
- [ ] 内容是否正确标注"广告"（如适用）？
- [ ] 对比照片使用是否合规？
- [ ] 标题是否避免夸大表述？
- [ ] 互动回复是否注意合规？
- [ ] 是否避免过度商业化推广？

### 微博
- [ ] 博文内容是否符合微博社区管理规定？
- [ ] 话题标签使用是否合适？
- [ ] 转发评论是否注意合规？
- [ ] 是否避免恶意营销行为？

## 发布后监控检查

### 用户反馈监控
- [ ] 是否有用户质疑内容真实性？
- [ ] 是否有关于效果夸大的投诉？
- [ ] 是否有违规内容的举报？
- [ ] 用户评论是否需要合规引导？

### 平台反馈监控
- [ ] 内容是否被平台限流或警告？
- [ ] 账号是否收到违规通知？
- [ ] 内容展现数据是否异常下降？
- [ ] 是否需要主动修改或删除内容？

## 定期合规评估清单

### 月度评估
- [ ] 本月发布内容是否全部经过合规审核？
- [ ] 是否收到任何投诉或举报？
- [ ] 团队合规意识是否需要加强？
- [ ] 审核流程是否有效执行？

### 季度评估
- [ ] 相关法规是否有新变化？
- [ ] 平台规则是否有更新？
- [ ] 合规培训是否需要更新？
- [ ] 审核标准是否需要调整？

### 年度评估
- [ ] 整体合规情况是否良好？
- [ ] 是否建立完善的合规体系？
- [ ] 是否需要外部合规审计？
- [ ] 明年合规重点是什么？

## 应急处理检查清单

### 收到投诉时
- [ ] 是否在24小时内响应？
- [ ] 是否及时核实投诉内容？
- [ ] 是否采取适当的处理措施？
- [ ] 是否记录处理过程和结果？

### 发现违规内容时
- [ ] 是否立即停止传播？
- [ ] 是否及时删除或修改？
- [ ] 是否分析违规原因？
- [ ] 是否采取预防措施？

## 团队合规培训检查清单

### 培训内容
- [ ] 相关法律法规解读
- [ ] 禁用词汇和表述规范
- [ ] 平台规则和要求
- [ ] 案例分析和经验分享

### 培训效果
- [ ] 团队成员是否理解合规要求？
- [ ] 是否掌握具体操作规范？
- [ ] 是否建立合规意识？
- [ ] 是否需要定期回训？

---

**使用说明**：
1. 建议每次内容发布前都使用本检查清单进行全面审核
2. 根据实际情况可适当调整检查项目
3. 定期更新检查清单，确保与最新法规要求保持一致
4. 建立检查记录档案，便于追溯和改进

**重要提醒**：合规是医美IP建设的底线要求，任何侥幸心理都可能导致严重后果。宁可内容平实一些，也不能触碰法律红线。
